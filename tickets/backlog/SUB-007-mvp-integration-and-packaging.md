# SUB-007: Integrate and package the MVP

- Status: Backlog
- Priority: P0
- Owner: Unassigned
- Depends on: SUB-003, SUB-004, SUB-005

## Objective

Deliver a repeatable local MVP that translates Chrome tab audio into English
subtitles on the supported Windows system.

## Scope

- End-to-end startup and shutdown workflow.
- Compatibility and recovery testing.
- Privacy and network verification.
- Reproducible local release artifacts and checksums.
- User setup, troubleshooting and uninstall documentation.

## Non-goals

- Public auto-update infrastructure and signed store distribution.

## Acceptance criteria

- [ ] A clean installation completes the documented happy path.
- [ ] Start, stop, reconnect and component failure cases are verified.
- [ ] No captured content or unexpected request leaves loopback.
- [ ] Release artifacts contain no secrets, models, logs or recordings.
- [ ] Known limitations and measured latency are documented.
