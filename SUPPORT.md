# Support

Submarine is an early open-source project and is provided without a commercial
support commitment.

## Getting help

Before opening an issue:

1. Read the setup and troubleshooting sections in [README.md](README.md).
2. Run `.\scripts\check.ps1`.
3. Confirm the backend listens on `127.0.0.1:8765`.
4. Record component versions and content-safe error messages.

Use a GitHub issue for reproducible bugs and feature requests. Do not attach
recordings, transcripts, `.env` files, tokens, model files, personal paths or
full diagnostic logs.

Suspected security vulnerabilities must use the private process in
`SECURITY.md`, not a public issue.
